# Спільна рубрика для двох відповідей

Прочитайте до першого запуску; критерії протягом порівняння не змінюйте.

Для кожного критерію ставиться 0, 1 або 2 бали та наводиться конкретний фрагмент відповіді. Невідоме, яке відповідь чесно позначила, відрізняється від необґрунтованої гарантії.

| Критерій | 0 | 1 | 2 |
| --- | --- | --- | --- |
| Обов’язкові обмеження | Є явне порушення або необґрунтована заява про їх гарантоване виконання | Явних порушень не виявлено, але частина відповідності ще не підтверджена й це зазначено | Виконання всіх заданих обов’язкових умов обґрунтовано |
| Різноманітність | Один принцип під різними назвами | Є змістові відмінності, але три окремі концепції не обґрунтовано | Три змістовно різні способи з поясненням принципів |
| Перевірюваність | Істотні твердження без підстав, невідоме приховано | Є джерела чи розрахунки, але лишилися конкретні прогалини | Характеристики простежуються до даних, розрахунки коректні, невідоме й наступні перевірки названо |
| Формат | Неможливо зіставити записи або більшість полів пропущено | Порівняння можливе, але бракує запису/поля | Три записи та всі задані поля |

Сума 0–8 є лише стислим описом якості відповіді. **Допуск конструкції перевіряють окремо:** порушення жорсткої умови не компенсується балами за формат. Дані наших карток не підтверджують повну затримку системи.
