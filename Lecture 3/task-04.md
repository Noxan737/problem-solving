# Завдання 4. Приберіть джерело

**Час:** 12 хв. **Блок:** 3.4. **Інструмент:** [інтерактивний журнал](lab.html) або [шаблон](report-template.md).

1. Незалежно перерахуйте комплект: база + один M + один S. Покажіть кількості, ціни, одиниці та результат. Калькулятор або Python дозволені; повторне запитання асистенту не замінює перевірки.
2. Виберіть одну характеристику відповіді, знайдіть її підставу в картці й назвіть межу висновку. Умовна картка є джерелом лише в межах цієї навчальної моделі.
3. Створіть **D-minus-S**: залиште базу, вимоги та картку M; вилучіть картку S **і всі дублікати її ціни, напруги та струму**, зокрема в прикладах, таблицях і попередніх відповідях. Збережіть точний текст зміненого входу. Залишити назву S як невідомий компонент можна.
4. **До запуску** запишіть, які твердження втратять підставу. Збережіть прогноз. Живий режим: третє й останнє звернення, інструкції P2 без змін, новий діалог, без вебпошуку. Без ШІ: оцініть C відносно D-minus-S.
5. Запишіть, де відповідь визнає прогалину, де продовжує стверджувати без підстави й що підтримує M. Якщо модель відмовилася від необґрунтованих тверджень, зафіксуйте це; помилку не потрібно вигадувати.
6. Завершіть журнал: «Очікував → змінив → отримав → перевірив → вирішив». Назвіть наступний потрібний тест чи джерело.

**Що здати:** незалежний розрахунок, перевірку характеристики, D-minus-S, прогноз, повну третю відповідь/позначку C та власне рішення.

**Самоперевірка:** чи немає витоку вилучених даних у новий контекст? Чи не оголошено невідоме значення нульовим? Чи збережена різниця між даними модуля та поведінкою цілого пристрою?
