# Лабораторна №3. Промпт під навантаженням

До лекції «ШІ в інженерній роботі: хороший запит теж треба тестувати». Одна індивідуальна робота на **45 хвилин**, чотири етапи. Потрібен браузер або текстовий редактор. Python необов’язковий; обладнання й платний доступ до ШІ не потрібні.

Мета: відрізнити пропозицію від факту, скласти самодостатній запит, порівняти результати за однією рубрикою та перевірити їх незалежно. Робота продовжує [лекцію 2](../Lecture%202/readme.md), але містить усі потрібні дані. Тут відвідувач перебуває **біля контейнера**; повідомлення працівнику в іншому кабінеті не перевіряємо.

## Запуск — 3 хвилини

1. Відкрийте [lab.html](lab.html), завантажте через **Download raw file** й відкрийте локальний файл браузером. GitHub показує HTML як код. Альтернатива: Code → Download ZIP, розпакувати репозиторій.
2. У тренажері є вхідні дані, рубрика, синтетичні відповіді й поля для роботи. Він не звертається до ШІ та не робить мережевих запитів. Власні запити виконуйте окремо в доступному асистенті.
3. Виберіть режим. **Живий:** максимум три звернення — P1, P2 на тих самих даних, P2 без картки S. **Без ШІ:** створіть власні P1/P2, оцініть заготовки A/B/C; це аналіз текстів, а не експериментальний доказ переваги вашого промпту.
4. Прочитайте [сценарій](scenario.md) та [рубрику](rubric.md) до першого запуску.

## Маршрут

| Інтервал | Завдання | Результат |
| --- | --- | --- |
| 0–3 хв | Підготовка | Обраний режим, прочитані правила |
| 3–11 хв | [1. Аудит п’яти тверджень](task-01.md) | Статус, джерело та пояснення |
| 11–21 хв | [2. Зберіть інженерний запит](task-02.md) | P1 і прогноз |
| 21–31 хв | [3. Перевірте ефект однієї зміни](task-03.md) | P2, дві оцінки, межа висновку |
| 31–43 хв | [4. Приберіть джерело](task-04.md) | Розрахунок, перевірка характеристики, стрес-тест |
| 43–45 хв | Експорт | Звіт і резервна копія |

Послідовність кожного досліду: **прогноз → дія → спостереження → перевірка → власне рішення**. Прогнози зберігайте до отримання відповіді. Необов’язкові Python-вправи виконують після основних 45 хвилин.

## Що здати

- `lab-03-report.md` з аудитом, повними P1/P2 та відповідями, рубрикою з доказами, незалежною перевіркою і висновком.
- `lab-03-progress.json` — резервна копія для тренажера. За ручного виконання достатньо [звіту](report-template.md).

Експорт відкрийте й перевірте. Автозбереження браузера може бути недоступне: орієнтуйтеся на повідомлення вгорі та зберігайте JSON. Кнопка «Показати звіт» дає текст для ручного копіювання. Журнал не відправляється викладачу автоматично. Перевірка заповнення полів не оцінює правильність; остаточне обґрунтування належить студенту.

## Критерії виконання

1. Кожен статус аудиту має підставу; нестача даних не названа доведеною хибністю.
2. P1 самодостатній; P2 змінює одну частину за незмінних вихідних даних; прогноз записано до запуску.
3. Чотири критерії застосовано до обох відповідей; для кожного бала є фрагмент тексту. Допуск конструкції розглянуто окремо.
4. Є незалежний кошторис, перевірка характеристики й аналіз втрати джерела; журнал відділяє відповідь асистента від власного рішення.

Оцінювання: 2 бали за метод, 1 за дослід зі зміною умови, 1 за перевірку, 1 за власний висновок. Режим без ШІ та ручне виконання не знижують оцінку. Відповідність плану: блоки 3.1–3.4, питання **Е05–Е06** із наданого банку.
