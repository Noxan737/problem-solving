# Для викладача: лабораторна №3

## Чотири ідеї

1. **Де асистент корисний:** студент розділяє факти, пропозиції та невідоме; посилається на конкретний фрагмент картки. Ознака засвоєння — зміна статусу після вилучення доказу без оголошення твердження хибним.
2. **Будова запиту:** студент передає задачу, контекст, дані, обмеження, формат і критерії. Ознака засвоєння — самодостатній P1, який не потребує історії чату.
3. **Порівняння за правилами:** одна рубрика й незмінні дані, одна обґрунтована зміна інструкції. Ознака засвоєння — докази для кожної оцінки та відділення якості відповіді від допуску конструкції.
4. **Перевірка та журнал:** незалежний перерахунок, простежуваність характеристики, контрольований брак джерела. Ознака засвоєння — власне рішення з межами доказовості, а не переписана відповідь ШІ.

## Організація

План: 3 + 8 + 10 + 10 + 12 + 2 = 45 хв. Таймінг плановий, не підтверджений проходженням реальною студентською групою. Перед P1 студенти читають рубрику. Максимум три живі звернення, без API або платної підписки. У резервному режимі A/B/C є синтетичними текстами; власні P1/P2 не називають причиною цих відповідей.

Тренажер перевіряє лише заповненість, зберігає прогнози й експортує журнал. Він не оцінює правильність відкритих відповідей. Показ заготовок доступний з початку: це відкрита лабораторна, а не захищений тест. Студентів просимо спершу фіксувати прогноз.

Критерії: метод — 2 бали (аудит 1, промпт і спільна рубрика 1); зміна умов — 1; незалежна перевірка — 1; власний висновок — 1. Сума 0–8 у рубриці характеризує відповіді, а не оцінку студента. Не винагороджуйте кількість викликів ШІ або складність Python.

A0/B/C містять навмисні недоліки. Не виправляйте їх як друкарські помилки: студенти мають перевірити ці тексти. Готові розв’язки не включено. Достатність аргументу оцінюйте за картками, арифметикою та явним позначенням невідомого. Повна працездатність конструкції не підтверджується цими картками.

## Зв’язок з екзаменом

**Е05:** побудова промпту для трьох концепцій, контекст/обмеження/формат/приклад, типи тверджень для перевірки — завдання 1–2.

**Е06:** чесне порівняння, чотири критерії, перевірка розрахунку/характеристики, межі одного запуску та журнал — завдання 3–4.

Номери взято з наданого плану. Окремого документа про офіційне затвердження переліку не надано.
