# Завдання 3. Перевірте ефект однієї зміни

**Час:** 10 хв. **Блок:** 3.3. **Інструмент:** [інтерактивний журнал](lab.html) або [шаблон](report-template.md).

Працюйте за [однією рубрикою](rubric.md). У живому режимі порівнюємо R1/R2, у резервному — A/B.

1. Оцініть перший текст за чотирма критеріями 0–2. Для кожного бала випишіть конкретний фрагмент і пояснення.
2. Виберіть одну слабкість. Скопіюйте P1 у P2 та змініть **одну інструкцію або одну секцію**. Картки, бюджет, контекст, модель і доступні налаштування залиште тими самими. Запишіть точну зміну й прогноз її ефекту **до запуску**.
3. Живий режим: друге звернення в чистому діалозі; збережіть R2 повністю. Якщо сервіс додає пам’ять чи прихований контекст, вкажіть цю межу контролю. Без ШІ: оцініть B; власний P2 залишається неперевіреним запитом, а не причиною появи B.
4. Заповніть чотири оцінки другого тексту. Порівняйте зміни за кожним критерієм; сума не замінює аналізу.
5. Окремо визначте: які концепції суперечать жорстким умовам, для яких відповідність не встановлена, що можна рекомендувати лише як кандидата на перевірку. Поясніть, чому одного результату недостатньо для висновку про стабільність.

**Що здати:** P2, точну зміну, прогноз, другу відповідь, вісім оцінок із доказами, висновок із межами застосовності.

**Самоперевірка:** чи не змінили ви дані одночасно з промптом? Чи не поставили високий бал лише за красиву таблицю? Чи відділили оцінку тексту від допуску конструкції?
