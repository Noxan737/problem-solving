# Виконання без тренажера

Відкрийте `scenario.md`, `responses.md`, `rubric.md` і скопіюйте `report-template.md` у свій документ. Усі дані містяться в цій папці. Виконайте task-01…04 за тим самим таймінгом. Для обчислень достатньо калькулятора.

У режимі без ШІ оцініть A0, A, B, C; P1/P2 напишіть самі. У звіті прямо зазначте, що заготовки не створено вашими запитами. Не робіть висновку, що P2 поліпшив модель. Порівняння дає оцінку текстів і план майбутнього експерименту.

Прогнози запишіть перед відкриттям відповідного тексту. Збережіть початкову редакцію перед виправленням. Для стрес-тесту перепишіть вхід без S і всіх її числових даних. Наприкінці здайте один заповнений документ із повними запитами, відповідями та обґрунтуваннями; JSON не потрібний.
