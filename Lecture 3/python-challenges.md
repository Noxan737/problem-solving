# Необов’язкові Python-вправи

Не входять до обов’язкових 45 хвилин. Можна виконати після здавання основного звіту. Відкрийте [starter.py](starter.py) у наявному Python 3; сторонні бібліотеки не потрібні.

## 1. Формат не дорівнює правильності

Заповніть `missing_fields`, щоб вона повертала назви відсутніх/порожніх полів principle, data, calculation, unknown, test. Перевірте повний словник, відсутній ключ і рядок із пробілів. Критерій: правильний список відсутніх полів; текст «невідомо» є заповненим полем. Створіть повний, але змістовно хибний запис та поясніть, чому ця функція його не викриває.

## 2. Незалежний кошторис

За `scenario.md` внесіть компоненти та ціни у власний список. Реалізуйте `total_cost` як суму кількість × ціна. Перевірте один M, один S і їх поєднання з базою. Окремий контроль для іншого об’єкта: дві деталі по 70 і одна по 30 мають давати 170. Порожній список має давати 0. У звіті збережіть вхідні числа й одиниці.

## 3. Ціна невідома

Позначте вилучену ціну S як `None`. Змініть функцію так, щоб за наявності невідомої ціни вона повертала `None`, а не нульову ціну чи попереднє число. Критерій: відомий комплект обчислюється; комплект із невідомою складовою не має точного підсумку. Відомий нуль і відсутнє значення мають різну поведінку.
